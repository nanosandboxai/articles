# More Code Agents and Continuous Improvements

We are expanding agent compatibility so teams can run more code agents in the same sandbox model.
Current targets include Gemini CLI and Grok CLI.

## What This Means

- More teams can standardize on one isolation model across different agent tools.
- Existing workflows can migrate with less custom glue code.
- Improvements ship continuously across install flow, runtime reliability, and developer ergonomics.

## Why It Matters

Agent ecosystems change quickly. A sandbox platform should keep pace with new tools while getting simpler and more stable with every release.
