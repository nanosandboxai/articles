# CLI Desktop App (Tauri Wrapper)

We are building a desktop app that wraps the `nanosb` CLI in a terminal-first interface powered by Tauri.

## What This Means

- The same CLI workflows remain the core interaction model.
- Teams get a desktop entry point with better session management and discoverability.
- Local-first behavior stays intact, with no change to the sandbox isolation boundary.

## Why It Matters

Many teams want the power of CLI workflows with the convenience of a desktop shell. A Tauri wrapper gives both without replacing the existing command-line interface.
