# Custom Deep Agent Support

Teams should be able to build their own deep agents and run them as first-class sandbox workloads.

## What This Means

- Custom agents can use the same isolation boundary as built-in flows.
- Teams can keep one lifecycle model for startup, execution, teardown, and monitoring.
- Security controls and runtime observability stay consistent across all agent types.

## Why It Matters

Agent ecosystems move fast. A sandbox platform must support built-in agents and custom agents with the same operational guarantees.
