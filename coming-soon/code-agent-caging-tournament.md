# Code Agent Caging Tournament

We are preparing a public caging tournament where code agents are pushed against controlled escape challenges.

## What This Means

- Agents attempt to break containment under defined rules and threat models.
- Escape attempts and outcomes are documented with repeatable test scenarios.
- Findings feed directly into sandbox hardening priorities and release planning.

## Why It Matters

Containment claims should be tested in public, not only described in docs. A caging tournament creates measurable pressure and transparent results.
