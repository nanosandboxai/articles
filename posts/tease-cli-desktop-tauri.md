The terminal, with a desktop home.

We're building a desktop application that wraps the `nanosb` CLI in a terminal-first interface powered by Tauri. Same workflows, same sandbox boundary, same local-first behavior — just easier to launch, manage sessions, and discover features.

Power users keep their CLI. Teams that prefer a desktop entry point get one. Nothing changes about the isolation model underneath.
