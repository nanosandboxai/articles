Coming next: first-class SDKs.

The CLI is a strong starting point, but many teams want to embed sandbox orchestration directly in their own stacks. We're working on native SDKs for Python, TypeScript, Go, Rust, Java, and C#.

Two integration levels are in the design:
- High-level: typed APIs that mirror `sandbox.yml` semantics in code.
- Low-level: a minimal lifecycle interface for teams bringing their own agent runtime.

Same isolation model. Native language ergonomics.

Preview: https://nanosandbox.ai/coming-soon/multi-language-sdks
